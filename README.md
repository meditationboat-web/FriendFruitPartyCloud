# Friend Fruit Party

Independent two-player fruit game imported from the supplied Unity package.

- Unity 2022.3.25f1
- Android ARM64 / IL2CPP / OpenGLES3
- Scene: Assets/MediaPipeUnity/Samples/Scenes/Face Landmark Detection/Face Landmark Detection.unity
- Menu: pose gestures. Gameplay: face movement and mouth opening.
- Camera background and runner lifecycle fixes included.

## Unity Build Automation
Create a separate Unity Cloud project, connect this repository (main, root folder /), use Unity 2022.3.25f1 and Android APK. Enable Git LFS downloads. No local build required.

Source and dependency licenses are preserved. This repository is separate from GestureFishCatchCloud.
